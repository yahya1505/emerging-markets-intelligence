# GitHub Publication Checklist

- [ ] Open the PBIX and verify all three pages and report interactions.
- [ ] Add genuine screenshots from the current dashboard to `screenshots/`.
- [ ] Confirm indicator codes and units match the API extraction configuration.
- [ ] Confirm methodology matches the SQL scoring implementation and Power BI measures.
- [ ] Verify setup instructions on a clean Python environment.
- [ ] Verify the database base table and unique key prerequisites are documented.
- [ ] Test one manual pipeline run and inspect its logs.
- [ ] Test repeated runs for duplicate prevention and correct row counts.
- [ ] Configure scheduler environment variables without hardcoding credentials.
- [ ] Ensure `.venv`, logs, API response caches, secrets, and temporary files are not tracked.
- [ ] Add LinkedIn/portfolio URLs to the README.
- [ ] Confirm the repository is appropriate for public access.
